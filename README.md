## Layihədəki Fayllar
- index.html - İstifadəçi haqqında məlumatlar, sadə CSS stil qaydaları olan əsas HTML səhifəsi.
- app.py - İstifadəçidən ad və yaş məlumatlarını alıb ekrana çıxaran Python skripti.
- README.md - Layihə haqqında ümumi məlumat və istifadə olunan Git komandaları.

## İstifadə Olunan Git Komandaları
1. git init - Qovluqda yeni Git repozitoriyası yaradır.
2. git clone <link> - Mövcud repozitoriyanı kompyuterə yükləyir.
3. git status - Faylların vəziyyətini (dəyişiklikləri) yoxlayır.
4. git add <fayl> - Dəyişiklikləri izləmə sahəsinə əlavə edir.
5. git commit -m "mesaj" - Dəyişiklikləri versiya olaraq yaddaşa yazır.
6. git switch -c <branch_adı> - Yeni branch yaradıb ona keçir.
7. git push origin <branch_adı> - Kodları GitHub-a göndərir.
8. git checkout <branch_adı> - Branch-lar arasında keçid edir.
